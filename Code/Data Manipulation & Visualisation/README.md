# Data Manipulation & Visualisation

Tugas manipulasi dan visualisasi data Titanic.

## Daftar Assignment

| No | File | Deskripsi |
|---|---|---|
| 1 | `assignment1.py` | Membaca dan menampilkan dataset |
| 2 | `assignment2.py` | Menghitung jumlah baris dan kolom |
| 3 | `assignment3.py` | Mengambil kolom fitur |
| 4 | `assignment4.py` | Mengambil kolom Survived |
| 5 | `assignment5.py` | Menambahkan fitur Relatives |
| 6 | `assignment6.py` | Menghitung penumpang setiap Pclass |
| 7 | `assignment7.py` | Menghitung penumpang berdasarkan Sex |
| 8 | `assignment8.py` | Menghitung data Survived setiap Pclass |
| 9 | `assignment9.py` | Membuat visualisasi Sex |
| 10 | `assignment10.py` | Membuat visualisasi Age |

Jalankan file dari folder ini:

```bash
python assignment1.py
```

Semua assignment juga dapat dijalankan melalui:

```bash
python titanic_assign.py
```
