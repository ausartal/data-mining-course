# Validation Model

Tugas mata kuliah Data Mining - Validation Model.

Validasi model k-NN pada data Titanic menggunakan Hold-Out, 10-Fold Cross Validation, dan Leave-One-Out.

## Dataset

Dataset yang digunakan: **titanic.csv**

## Daftar Assignment

| No | File | Deskripsi |
|----|------|-----------|
| 1 | `assignment1.py` | Load dataset dan tampilkan |
| 2 | `assignment2a.py` | Hold-Out method 70% - 30% |
| 2 | `assignment2b.py` | 10-Fold Cross Validation |
| 2 | `assignment2c.py` | Leave-One-Out (LOO) |
| 3 | `assignment3a.py` | Ambil kolom fitur (Sex, Age, Pclass, Fare) Hold-Out |
| 3 | `assignment3b.py` | Ambil kolom fitur (Sex, Age, Pclass, Fare) 10-Fold |
| 3 | `assignment3c.py` | Ambil kolom fitur (Sex, Age, Pclass, Fare) LOO |
| 4 | `assignment4a.py` | Ambil kolom kelas (Survived) Hold-Out |
| 4 | `assignment4b.py` | Ambil kolom kelas (Survived) 10-Fold |
| 4 | `assignment4c.py` | Ambil kolom kelas (Survived) LOO |
| 5 | `assignment5a.py` | Normalisasi data latih Hold-Out |
| 5 | `assignment5b.py` | Normalisasi data latih 10-Fold |
| 5 | `assignment5c.py` | Normalisasi data latih LOO |
| 6 | `assignment6a.py` | Normalisasi data uji Hold-Out |
| 6 | `assignment6b.py` | Normalisasi data uji 10-Fold |
| 6 | `assignment6c.py` | Normalisasi data uji LOO |
| 7 | `assignment7a.py` | K-NN Hold-Out dan hitung error ratio |
| 7 | `assignment7b.py` | K-NN 10-Fold dan hitung error ratio |
| 7 | `assignment7c.py` | K-NN LOO dan hitung error ratio |

Keterangan suffix:

- `a` = Hold-Out
- `b` = 10-Fold Cross Validation
- `c` = Leave-One-Out

## Cara Menjalankan

```bash
python assignment1.py
python assignment2a.py
python assignment2b.py
python assignment2c.py
...
python assignment7c.py
```
