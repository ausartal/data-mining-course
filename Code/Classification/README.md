# Classification

Tugas klasifikasi data Titanic menggunakan metode k-Nearest Neighbor.

## Dataset

- `titanic.csv`
- `titanic_test.csv`
- `titanic_testlabel.csv`

## Daftar Assignment

| No | File | Deskripsi |
|---|---|---|
| 1 | `assignment1.py` | Membaca dataset train |
| 2 | `assignment2.py` | Membaca dataset test |
| 3 | `assignment3.py` | Mengambil train data dan menghapus missing value |
| 4 | `assignment4.py` | Mengambil test data dan menghapus missing value |
| 5 | `assignment5.py` | Mengambil train label |
| 6 | `assignment6.py` | Mengambil test label |
| 7 | `assignment7.py` | Normalisasi train data |
| 8 | `assignment8.py` | Normalisasi test data |
| 9 | `assignment9.py` | Klasifikasi k-NN untuk k = 1 sampai 15 |
| 10 | `assignment10.py` | Menghitung error ratio setiap nilai k |

## Cara Menjalankan

Jalankan file dari folder ini:

```bash
python assignment1.py
python assignment2.py
python assignment3.py
python assignment4.py
python assignment5.py
python assignment6.py
python assignment7.py
python assignment8.py
python assignment9.py
python assignment10.py
```

Library yang digunakan adalah pandas dan numpy.
